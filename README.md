# AllForU — CloudStream Repo

MovieBox, Netflix, Hotstar & Prime Video — all in one place.

## Add to CloudStream

Add this repository URL in CloudStream (Settings → Extensions → Add repository):

```
https://raw.githubusercontent.com/RVRBEAST76/allforu-repo/main/repo.json
```

## Plugins

| Plugin     | Version | Content                  |
|------------|---------|--------------------------|
| MovieBox   | v29     | Movies, series, anime    |
| Netflix    | v88     | Movies & series          |
| Hotstar    | v83     | Movies & series          |
| PrimeVideo | v84     | Movies & series          |

> ⚠️ Old **StreamBox** users: uninstall it and install **MovieBox** (renamed).
